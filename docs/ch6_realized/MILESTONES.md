# Chapter 6 / REALM-Bench Tier 6 Milestones

## Scope

This work extends REALM-Bench with Tier 6: Cross-Episode Causal Loop.
It is not a standalone benchmark and not an orphan Quadrivium-only test.

Quadrivium/Mnemosyne is treated as one system submission to REALM-Bench
Tier 6.

## Claim boundary

Deterministic harness validation is not evidence for H1-H5. It validates
logging, schema, censoring, manifests, CTL/event exports, and scorer
regeneration.

Pilot and confirmatory runs are required before quantitative Chapter 6
claims about cross-episode learning.
